# 🔷 Slitherlink SAT Solver & GUI

A Python-based solver for the logic puzzle **Slitherlink**, using a SAT solver (`pysat`) and a Tkinter GUI for visualization and interaction.

---

## 🧩 What is Slitherlink?

Slitherlink is a logic puzzle where the player must draw a single continuous loop around a grid based on numerical clues.  
Each number represents how many of the cell's four edges are part of the loop.

---

## 🚀 Features

- ✅ SAT-based solver using `pysat` (e.g. Lingeling)
- 📄 Load puzzles from `.txt` files
- 🔄 Random puzzle generator (adjustable size)
- 🧠 Single-loop constraint enforcement
- 🖱️ Interactive Tkinter GUI:
  - Load & solve puzzles
  - Draw solutions manually
  - Verify solutions
  - Generate new puzzles

---

## Running the Application:
python main.py
